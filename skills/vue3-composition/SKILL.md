# Компоненты и реактивность Vue 3

- Посмотри установленную версию Vue, локальные инструкции и ближайший компонент с той же ролью. Для SFC на TypeScript следуй принятой форме `<script setup lang="ts">`. Используй доступные в этой версии макросы и существующие соглашения по стилям, переводам и UI-компонентам.
- Найди владельца изменяемого значения. Черновик одного поля обычно помещается в локальный `ref`. Чтобы два соседних компонента редактировали одно значение, подними его в ближайшего общего родителя. Для состояния между независимыми экранами или после размонтирования используй принятый в приложении стор. Фильтры, которые должны восстанавливаться по ссылке и при переходе назад, читай из маршрута.
- Передавай значения через типизированные props. Изменение родительского значения выражай событием либо принятым контрактом `v-model`. Например, при контракте `modelValue` поле отправляет `update:modelValue` с новым значением. Для формы с кнопкой «Отмена» выдели локальный черновик и переноси его в родительское состояние при подтверждении.
- Используй `computed` для производного значения, `watch` для эффекта. Следи за конкретным источником, например `() => props.id`. При асинхронной загрузке по меняющемуся идентификатору отменяй предыдущую операцию или проверяй её актуальность перед записью результата, ошибки и статуса загрузки.
- Выделяй `useX`, когда вызывающему коду нужно реактивное поведение или привязка к жизненному циклу. Создавай состояние экземпляра внутри функции. Чистое преобразование оставляй обычной функцией. Снимай созданные вручную подписки, обработчики и таймеры при завершении соответствующего эффекта или области видимости.
- В Pinia читай состояние и getters через объект стора. Если нужны отдельные реактивные ссылки, используй `const { items } = storeToRefs(store)`. Действия можно деструктурировать из самого стора. Получай стор в контексте установленной Pinia.
- После изменения props, emits или composable запусти проверку типов Vue из проекта. В затронутом сценарии проверь обновление входного значения после первого рендера. Для формы проверь подтверждение и отмену, для асинхронного эффекта — быструю смену источника.
